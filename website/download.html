Install in a minute

Open. Drag. Start finding.

  1. 1

    Open the downloaded DMG. macOS verifies the signed installer when you open it.

  2. 2

    Drag FileNest to Applications. This adds it to your standard Applications folder.

  3. 3

    Choose the folders you want to understand. Local mode works without an account.

Before you install

The boundary is your computer.

No account required for local mode. FileNest uses your operating-system account and the folders you select as its authorization boundary.

Cloud remains opt-in. File content is only sent to a cloud provider when you explicitly configure and use one for a chosen workflow.

Signed and notarized for macOS. The current DMG has an Apple notarization ticket and a Developer ID signature.

Built in public. FileNest is MIT licensed. Review the source, report issues, or contribute at github.com/filenestapp/filenest.

# Change Analysis: `0cda7bf` → 2026-07-17 Product Update

> Scope: committed baseline `0cda7bf` compared with product commit `839c410`. Stack: native macOS SwiftUI plus Windows Electron/React/TypeScript. Generated 2026-07-17 in Asia/Singapore.

## Summary

- **FEATURE** — Normal and Smart Search now have clearer product roles: normal search is the default low-latency path, while completed results offer slower AI interpretation as an explicit escalation.
- **ENHANCEMENT** — Library ranking merges lexical, date, metadata, note, content, and semantic evidence into confidence-oriented results.
- **FIX** — Chat generation no longer depends on the Chat page remaining visible; sidebar status communicates running and completed responses.
- **FEATURE** — Windows gains a main-process library query service, structured chunks, selective indexing controls, normalized settings, richer chat metrics, and broader typed IPC parity.
- **ENHANCEMENT** — Onboarding exposes generation and embedding model selection with Qwen 9B and Qwen Embedding 0.6B defaults.
- **FEATURE** — Both platforms expose a configurable global Quick Search that opens a centered floating search box and routes the query into Library.
- **REFACTOR** — Chunking, context planning, previews, persisted metadata, and fallback usage statistics now share one versioned token-accounting profile; exact Docling counts are preserved.
- **FIX** — Semantic chunking now prioritizes complete paragraphs and sentences, applies overlap once at the retrieval-child layer, repairs adjacent Docling sentence fragments, and halves a failing segment after an Ollama runner EOF.
- **CHORE** — Managed Ollama/PaddleOCR refresh and update handling is more deterministic, and the macOS run script now installs a stable signed Release build by default.

Overall risk: **Medium**. The macOS automated suite and Windows code-level gates pass, but the Windows change surface is broad and native Windows installer, shell, DPAPI, tray, startup, and update behavior still require platform acceptance.

## Change breadth

The implementation update touches the macOS application state, UI, AI/update services, storage, tests, Windows main process, preload contract, renderer, shared types, and build tooling. New Windows source files add library search, settings normalization, and an integration-oriented parity test suite. Product and engineering documentation is synchronized in the same commit.

## Notable changes and impact

### Search and retrieval

- Normal search remains debounced and automatic.
- Smart Search is removed from the search bar and offered after normal results with an explicit latency warning.
- AI search planning can stream a user-facing interpretation before vector retrieval begins.
- macOS search results sort by confidence, then raw score, with deterministic filename fallback.
- Windows search moves from renderer-side snapshot filtering to a typed service that supports lexical fields, semantic hits, relative/explicit dates, category filters, sort direction, and paging.

Impact: user behavior and internal renderer contracts change, but there is no public network API. Existing search data remains compatible because scores and confidence are derived, not persisted.

### Conversation lifecycle

- The macOS Chat view stays mounted across page changes, preserving the active stream and composer state.
- `AppState` tracks running, completed, stopped, and seen conversation state for sidebar feedback.
- Windows chat adds bounded history, retry replacement, cancellation, progress stages, file attachment state, response metrics, and retrieval-only fallback behavior.

Impact: chat state management changes substantially. Durable session/message formats remain additive; transient status is process-local.

### Indexing and persistence

- Windows adds structured chunk persistence and atomic metadata/chunk/vector replacement.
- Settings normalization clamps chunk size, overlap, RAG count, context window, scheduling, and extension lists.
- Selective rebuild modes distinguish all, unindexed, and embedding-only work.
- Organization refuses to move content that changed after indexing and distinguishes move, database, rollback, and rollback-failure paths.
- Managed-library reconciliation skips stable rows, imports new organized files, removes stale records, and reindexes offline metadata changes.
- Docling stores exact tokenizer counts when available; fallback paths store reproducible estimates with profile, version, and accuracy metadata. Legacy estimates are recalculated without clearing vectors or changing chunk boundaries.
- Oversized generated run-on text is split on complete lexical units using the same counter and overlap budget, while ordinary document sentences keep semantic boundaries.
- Parent and retrieval sizing are independently configurable. Defaults are 600 parent tokens, 300 retrieval tokens, and an 80-token maximum semantic overlap.
- Parent rows are backfilled only when their table is introduced, and unreferenced parent rows are removed on startup.
- Only an incompatible embedding space triggers automatic reconstruction. Parsing, OCR, chunking, scope, and endpoint changes keep the existing index usable and offer manual rebuild or skip choices.

Impact: additive local schema evolution. No destructive migration was detected. Stale-source and rollback guards reduce corruption risk.

### Local AI, onboarding, and updates

- Onboarding lets users choose local generation and embedding models while preserving explicit defaults.
- Ollama and PaddleOCR status refresh work is moved off blocking UI paths and can run concurrently.
- Ollama updates resolve the official macOS DMG asset from GitHub release metadata before installation.
- The build/run script defaults to Release and refuses an unintentional designated-requirement change.

Impact: activation and developer install behavior change. A stable Apple Development identity is now required for the canonical local installation path.

### Global Quick Search

- macOS registers a configurable Carbon hot key and presents a centered floating panel on the active display.
- Windows registers the platform accelerator through Electron, presents a frameless always-on-top search window, and reports shortcut conflicts in General settings.
- Submitted queries activate the main window, select Library, apply the query once, and then consume the transient request.

Impact: shortcut registration is process-local and may fail when another application owns the combination. Both platforms surface that state without replacing user data.
